# ИС «Библиус» — кейс 8 «Библиотека: выдача и просрочки»

Информационная система для библиотеки РТУ МИРЭА: учёт выдачи и возврата книг, автоматический расчёт просрочек,
учёт поступления и списания фонда. Веб-приложение (React + Node.js) и 1С:Предприятие 8.3.
