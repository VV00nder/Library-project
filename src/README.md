# Библиус – MVP

Рабочая версия ИС «Библиус» для защиты MVP 15.12.2026: веб-приложение для библиотекаря и читателя (React + Node.js) и учётное ядро в 1С:Предприятие 8.5.

```
Браузер (React) ──► Сервер приложения Node.js :3001 ──► IIS ──► HTTP-сервис 1С BibliusAPI ──► база 1С
                                                                     ▲
                                              Бухгалтер ── клиент 1С ┘
```

## Состав папки

| Путь | Что это |

| `onec/config/` | Выгрузка конфигурации 1С в XML (загружается в Конфигураторе) |

## Развёртывание с нуля (Windows)

Нужно: 1С:Предприятие 8.5 с модулем расширения веб-сервера, IIS, Node.js 20 или новее.

1. **База 1С.** Создайте файловую базу, откройте Конфигуратор → «Конфигурация → Загрузить конфигурацию из файлов» → папка `src\onec\config` → «Обновить конфигурацию базы данных» (F7).
2. **Пользователи 1С.** «Администрирование → Пользователи»: `admin` (роль АдминистраторБиблиус), `accountant` (БухгалтерБиблиус), `biblius_exchange` (ОбменБиблиус, не показывать в списке выбора). Пароли задайте свои.
3. **Публикация.** Конфигуратор, запущенный от имени администратора → «Администрирование → Публикация на веб-сервере»: имя `Biblius`, IIS, отметить «Публиковать HTTP-сервисы по умолчанию». Проверка: `http://localhost/Biblius/hs/biblius/ping` должен запросить пароль.
4. **Настройки сервера.** Скопируйте `server\.env.example` в `server\.env` и укажите пароль пользователя `biblius_exchange` в `ONEC_PASSWORD`.
5. **Учётные записи веб-приложения.** Скопируйте `data\demo-accounts.example.json` в `data\demo-accounts.json` и задайте пароли.
6. Запустите `seed-biblius.cmd` (один раз; повторный запуск безопасен).
7. Запустите `start-biblius.cmd` – откроется http://localhost:3001.
8. **Почта (по желанию).** Чтобы письма уходили читателям, заполните в `server\.env` параметры `SMTP_HOST`, `SMTP_PORT` (465, TLS), `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM`. Пока они пустые, письма (коды привязки билета, напоминания) сохраняются в `server\outbox` и видны библиотекарю в разделе «Уведомления». `REMIND_DAYS` – за сколько дней напоминать (3), `NOTIFY_TIME` – время рассылки по Москве (09:00).

## Сценарий демонстрации (7–10 минут)

1. Сайт без входа: главная, «Каталог» с поиском и разделами, карточка книги, «Новые поступления», «Популярное».
2. «Регистрация» → новая учётная запись → «Мои книги» → номер билета → код из письма (в режиме без почты – последнее письмо в `server\outbox` или в разделе «Уведомления» у библиотекаря) → билет привязан.
3. Карточка книги → «Взять почитать» → заявка видна во вкладке «Заявки».
4. Вход `librarian` → «Заявки читателей» → «Выдать». Затем «Выдача и возврат»: попробовать выдать уже выданный экземпляр – 1С откажет; принять возврат просроченной книги.
5. «Отчёт „Просрочки“»: KPI, статистика (средняя, медиана, ТОП-5), фильтр по группе, «Экспорт в CSV».
6. «Уведомления» → «Запустить рассылку»: письма о просрочке; повторный запуск ничего не отправляет.
7. «Импорт CSV»: повторная загрузка `data\readers.csv` – все строки «Пропущено»; «Журнал операций» – видны сделанные действия.
8. Клиент 1С под `accountant`: документ «Списание» для утерянного экземпляра, отчёт «Состав и стоимость фонда».

## API сервера приложения

Полное описание – `server/openapi.yaml` (OpenAPI 3; открывается в https://editor.swagger.io или в расширении OpenAPI для VS Code). Ошибки возвращаются как `{code, message, request_id}`. Списки книг, читателей, выдач, журнала и публичного каталога принимают `page` и `per_page` (до 200).

| Группа | Пути | Роль |
|---|---|---|
| Служебное | `GET /api/health` | – |
| Учётная запись | `/api/auth/login`, `/logout`, `/me`, `/register`; `/api/me/link/start`, `/api/me/link/confirm` | все / читатель |
| Публичный каталог | `GET /api/public/catalog`, `/api/public/catalog/:key` | – |
| Фонд, читатели | `/api/books`, `/api/readers` (GET/POST/PATCH/DELETE) | библиотекарь |
| Выдачи | `/api/loans`, `/api/loans/:id/return`, `/loss`; `GET /api/me/loans` | библиотекарь / читатель |
| Заявки | `/api/requests`, `/:id/cancel`, `/:id/reject`, `/:id/issue` | читатель / библиотекарь |
| Отчёты | `/api/reports/overdue`, `/export` (CSV), `/stats` | библиотекарь |
| Уведомления | `GET /api/notifications`, `POST /api/notifications/run` | библиотекарь |
| Импорт, журнал | `POST /api/import/books\|readers\|loans`, `GET /api/audit` | библиотекарь |

Формат CSV – UTF-8, разделитель «;», даты `YYYY-MM-DD`, десятичный разделитель – точка (ТЗ, ПР-04).

Инструкция пользователя с иллюстрациями – `Docs/Инструкция_пользователя_Библиус.docx`.

## Резервная копия и восстановление

Требование ТЗ (раздел 6) и проверка T-18.

1. Закройте Конфигуратор и клиент 1С. Запустите `backup-biblius.cmd` от имени администратора – на время копирования он остановит IIS. Копия появится в `src\backup\<дата_время>`: файл базы `1Cv8.1CD`, `env-без-паролей.txt` и `сведения.txt` с контрольной суммой. Папка `backup` в git не попадает.
2. Проверка восстановления: `restore-biblius.cmd "backup\<дата_время>" C:\Biblius-test`, затем в окне запуска 1С «Добавить → Добавление существующей базы» → `C:\Biblius-test` и сверить данные.
3. Возврат рабочей базы: `restore-biblius.cmd "backup\<дата_время>"` (от имени администратора). Текущая база сначала сохраняется в `backup\перед-восстановлением_<дата>`.

Путь к базе по умолчанию – `%USERPROFILE%\Documents\Biblius`; другой путь передаётся первым параметром `backup-biblius.cmd`.

## Безопасность

- Пароли веб-учёток хранятся в 1С только как хеш scrypt с солью. Регистрация ограничена 10 попытками за 10 минут с одного адреса.
- Билет привязывается только по коду из письма на e-mail из карточки читателя (6 цифр, 10 минут, не больше 5 попыток); один билет – одна учётная запись.
- В режиме без почты коды привязки лежат в `server\outbox` и видны библиотекарю – это допустимо только на учебном стенде.
- Пароль 1С знает только сервер приложения (`server\.env`); браузер к 1С не обращается.
- HTTP-сервис 1С принимает запросы только от пользователя с ролью ОбменБиблиус и проверяет права веб-пользователя на каждую операцию.
- Сервер слушает только `127.0.0.1`; для доступа из сети нужен обратный прокси с HTTPS.
